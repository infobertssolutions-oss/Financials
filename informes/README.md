# Informes

Esta carpeta se genera automáticamente ejecutando `scripts/generar_informes.py`. No edites estos archivos a mano — se sobrescriben cada vez que se ejecuta el script.

Hasta que no haya datos reales en `/datos/` (sustituyendo las filas marcadas como "FILA DE EJEMPLO"), los informes aparecerán vacíos o con avisos indicándolo.
