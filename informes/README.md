# Informes

Esta carpeta se genera automáticamente con `python3 scripts/generar_informes.py`. **No edites estos archivos a mano**: se sobrescriben cada vez que se ejecuta el script.

- `Estados_Financieros_Berts.xlsx`: Balance de Situación, Cuenta de Pérdidas y Ganancias, IVA, vehículos, libro diario y pendientes. Todo con fórmulas a partir del libro diario.
- `balance_situacion.md`, `cuenta_perdidas_ganancias.md`, `iva.md`, `rentabilidad_vehiculos.md`, `avisos.md`: las mismas cifras en texto.

Cómo está montado y qué criterios contables se aplican: [`../ESTADOS_FINANCIEROS.md`](../ESTADOS_FINANCIEROS.md).
